# 写真書き出し（Web 版）

ブラウザだけで動く写真書き出しツールです。画像はすべてブラウザ内で処理され、サーバーには送信されません。

- 推奨ブラウザ：Google Chrome / Microsoft Edge（保存先フォルダに直接書き出し）
- Safari / Firefox：ZIP でダウンロード
- 初回のみ AI モデル（約 176MB）を読み込みます。2 回目以降はブラウザに保存されたものを使います。

## 使い方
1. 同じグループの元画像 4 枚をまとめてドロップ（ファイル名で自動振り分け）
   - `top` / `main` / `wide` を含む → main · wide · top
   - `profile` を含む → profile
   - `text1` / `text2` を含む → text01 / text02（サイズ調整のみ）
2. 下の 6 つのサムネイルから選び、右のパネルで微調整
3. 「書き出し」→ 保存先フォルダ内の「グループ名」フォルダに 6 ファイル

出力：JPEG 品質 94 / プログレッシブ / 4:4:4 / 300ppi / sRGB IEC61966-2.1 埋め込み

## ルールの変更
`engine.js` 冒頭の `PRESETS` の数値を変更してください。
